The Daily Journal
=================
Open index.html in any modern browser (Chrome, Safari, Edge, Firefox).

- Entries save automatically in your browser (localStorage), per device and per browser.
- Always open it from the same location/URL, or your entries will appear missing.
- Fonts load from Google Fonts when online; it falls back to system serif fonts offline.
- To host it, upload index.html to any static host (GitHub Pages, Netlify, etc.).
